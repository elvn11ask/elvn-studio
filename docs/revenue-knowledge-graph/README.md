# Revenue Knowledge Graph public documentation

This directory documents the public boundary of the ELVN Revenue Knowledge Graph module. The module is a projection and intelligence layer for ELVN Revenue Operations. It does not replace catalogs, CRM, ERP, finance systems, or the workflow records they own.

Public pages:

- `/revenueos/knowledge-graph`
- `/revenueos/knowledge-graph/architecture`
- `/revenueos/knowledge-graph/use-cases`
- `/revenueos/knowledge-graph/ai`
- `/revenueos/knowledge-graph/security`
- `/revenueos/knowledge-graph/pricing`
- `/revenueos/knowledge-graph/faq`
- `/news/revenue-knowledge-graph`

The safe example package is in `public-package/revenue-knowledge-graph`. Detailed schemas, source mappings, operational rules, customer data, and deployment configuration remain private.
