# RevenueOS public GitHub release checklist

- [ ] Repository purpose is public competence demonstration, not production distribution.
- [ ] README states Private Implementation Program and links to the ELVN Studio product page.
- [ ] No production source, schema, migration, workflow engine, attribution engine, SLA logic, pricing intelligence, AI prompts, or administrative backend.
- [ ] No infrastructure topology, hostnames beyond public sites, credentials, environment values, logs, private reports, or customer data.
- [ ] All examples use synthetic organizations, people, products, suppliers, prices, and identifiers.
- [ ] Public event examples are deliberately reduced and do not reveal the complete taxonomy.
- [ ] API contracts are redacted and versioned as examples, not represented as the production API.
- [ ] Webhook verifier and SDK contain no business logic.
- [ ] Security and privacy documents avoid unverified certifications.
- [ ] License, copyright, trademark, third-party trademark, contribution, and support notices are explicit.
- [ ] Secret scan, dependency review, license review, and manual IP review pass.
- [ ] Screenshots are redacted and metadata removed.
- [ ] Owner signs the public claims register.
- [ ] Release has a revocation and takedown plan.

Recommended repository name: `revenueos-by-elvn`.

Do not create or publish the repository until every item is complete and the product name receives legal clearance.
