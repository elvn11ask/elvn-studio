## Public claims

Manufacturer Intelligence combines governed manufacturer connectors, exact manufacturer + complete MPN identity, datasheet intelligence, field-level provenance, optional customer-approved AI assistance, human review, and controlled publication.

AI is not the source of truth. No connector or model publishes directly. Current availability is limited to selected private implementation engagements.

## Private boundary

This package contains no connector implementation, manufacturer-specific rules, source URLs or access methods, real SKU outputs, production adapters, extraction prompts, proprietary evidence schemas, conflict algorithms, credentials, infrastructure details, or customer/supplier data.

## Release note summary

Public in this preview: product page, product positioning, typical engagement ranges, news, discovery links, public architecture and documentation.

Not generally available: production connector library, automatic publication, certified ICPROM/ChipFasteners enrichment, or full manufacturer coverage.
